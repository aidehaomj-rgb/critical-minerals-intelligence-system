# 矿策图谱

中国关键矿产政策情报平台，数据口径截至 2026 年 7 月 2 日。

## 使用方式

直接双击 `index.html` 即可使用。页面不依赖构建工具、后端服务或第三方资源。

如需通过本地服务器预览，可在本目录运行：

```powershell
npx serve .
```

## 主要功能

- 可扩展的应用外壳、左侧模块导航与 Hash 路由
- 当前“关键矿产清单”作为第一个正式业务页面
- 预留情报总览、关键矿产库、国别政策、时间轴、来源库和研究报告模块
- 按关键词、状态和年份筛选政策
- 全局快捷搜索（`Ctrl/Cmd + K`）
- 点击政策记录查看管制范围、管制手段及官方来源
- CSV 清单导出与摘要复制
- 桌面、平板和移动端响应式布局

## 文件结构

- `index.html`：应用外壳与公共界面
- `styles.css`：设计系统、页面组件和响应式样式
- `app.js`：页面路由、政策数据和交互逻辑

## 说明

本系统用于研究和合规初筛，不构成法律意见。开展具体出口业务时，应核对最新两用物项出口管制清单、税则号列和主管部门解释。

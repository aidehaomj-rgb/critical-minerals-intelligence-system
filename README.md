# 关键矿产情报采集分析系统

> 以开源情报为基础、智能分析为支撑，面向关键矿产出口管制、供应链态势与风险研判场景构建的一体化情报工作台。

本项目将政策公告、矿产清单、市场态势、开源情报、执法案例、研究资料和专题报告组织到统一界面中，形成“情报感知—分析研判—成果输出”的业务闭环。

当前版本为可在本地运行的前端原型，采用原生 HTML、CSS 和 JavaScript 构建，无需打包编译。页面数据更新口径截至 **2026-07-02**。

## 能力架构

```mermaid
flowchart LR
    A["情报感知层<br/>政策 · 市场 · 执法 · 案例 · 文件"] -->
    B["分析研判层<br/>时间轴 · 问答 · AI分析 · 图谱 · 路径"] -->
    C["决策输出层<br/>深度研究 · 海关要情 · 综合呈报 · 课题报告"]
```

系统功能分为三个板块：

1. **情报工作台**：持续汇聚政策、矿产、市场、开源信息和研究资料。
2. **战术—研究工具**：围绕具体矿产、企业、国家、政策和物流链路开展分析。
3. **战略—报告生成**：将证据、观点和图表沉淀为可审核、可归档的研究成果。

## 工作亮点

- **政策颗粒度下沉到商品**：将组合公告拆分到钐、钆、铽、镝、镥、钪、钇等单项商品，便于逐项检索和核验。
- **暂停政策单独建模**：暂停公告、暂停期限和原管制公告同时保留，趋势统计按业务规则扣减。
- **公告—商品—编码—税号联动**：在政策详情之外形成独立税号清单，方便业务识别和导出。
- **情报只展示最新批次、历史自动沉淀**：开源情报页面突出最新采集结果，历史资料统一进入文件库。
- **事实与研判边界可见**：AI 分析强调时间窗口、政策适用范围、证据等级和待核查事项，避免将管制前正常贸易直接判定为违规。
- **研究成果可直接复用**：深度研究的主要观点、证据、图表和 Word/PDF 报告可在系统内查看和归档。
- **本地优先运行**：当前原型无需云端服务即可浏览，适合内网部署和后续对接本地大模型。

- Windows 10/11
- Node.js 18 或更高版本

## 数据说明

- 关键矿产态势中的出口量采用 **2023 年 = 100** 的指数化展示，便于跨矿种比较。
- 海外价格为代表性产品规格的参考展示，并不代表全部品级或实时成交价格。
- 国家政策、国外反制和替代项目用于态势研判，应结合最新官方公告和项目进展复核。
- 文件库包含本地导入资料，部署到其他环境时应同步复制 `library/`、`reports/` 及其索引文件。
- 当前项目尚未接入生产数据库、实时行情、图数据库、贸易提单系统或大模型 API。

## 使用边界

本系统用于情报研究、风险初筛和业务辅助，不构成法律意见、行政认定、交易建议或执法结论。开展具体出口业务或案件核查时，应以最新法律法规、主管部门公告、两用物项管制编码、海关税则和正式许可文件为准，并对模型生成内容进行人工复核。
